# Presently

Presently is a feature-rich AI presentation builder inspired by tools like Gamma.app. The goal is to help users quickly create polished, structured slide decks with AI-assisted generation and editing.

## Tech Stack

- React
- TanStack Start
- TanStack Router
- TanStack Query
- Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

The app runs on `http://localhost:3000`.

## Scripts

```bash
npm run build
npm run test
npm run lint
npm run format
```
